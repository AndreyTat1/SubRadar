# Дорожная карта

- **Smart Detect.** Импорт подписок из чеков, PDF и писем с явного согласия пользователя.
- **AI Insights.** Анализ регулярных расходов и объяснимые рекомендации.
- **Cloud Sync.** Добровольная синхронизация и резервное копирование. Планируемый REST API на PHP 8.3+, Yii2 и PostgreSQL. Retrofit и OkHttp подключаются при появлении API.
- **Family.** Совместный учёт семейных подписок с разграничением доступа.
- **Banking.** Интеграция через официальные банковские API с отдельным согласием.
- **SubRadar Pro.** Платные возможности через Google Play Billing.

Для публикации нужно настроить подпись релизов и проверить требования Google Play на дату отправки.
