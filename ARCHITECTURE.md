# Архитектура SubRadar

Приложение состоит из одного Gradle-модуля `app`. Пакеты отделяют модель и бизнес-правила от Room, Android API и Compose.
Прогноз прошлых дат строится по текущим правилам повторения и истории цен. Изменение расписания или статуса влияет на пересчёт ожидаемых сумм. История цен использует локальную дату сохранения новой стоимости. Курсы валют не используются. Графики преобразуют в числа с плавающей запятой только координаты отрисовки.

## Напоминания и резервные копии

WorkManager запускает проверку раз в четыре часа и ставит внеочередную проверку после изменений. Android определяет фактическое время выполнения. Ключ дедупликации включает подписку, дату события, тип и календарный день уведомления. Служебные отметки о доставке хранятся локально. Системное разрешение проверяется при каждой фоновой проверке.
